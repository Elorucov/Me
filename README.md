# Elchin Orujov's personal page

Source code of the main page of [elor.top](https://elor.top)

## Technologies

PHP, HTML, CSS and... that's all.

AI was used only once — to explore options for implementing localization. The design was invented by me, and the code was also written by me.

## Information for developers

All you need is a web server and PHP. That’s it. There’s no need for any "build tools" or "compilers" — you simply upload the files to your server.

This page doesn’t even use JavaScript, let alone libraries like React; as a result, it loads and opens faster and has a smaller file size.

Due to the way the tabs are implemented, the page will only display correctly in modern browsers (from around 2023 onwards).
